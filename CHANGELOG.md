# Changelog

Toutes les modifications notables de ce projet seront documentées dans ce fichier.

## [1.3.0] - 2026-08-03

### Ajouté
- Mode "Compétition en Équipe" : Ajout d'un champ "Numéro de Test" sur la page d'accueil. Ce champ permet de générer des "Sets de Tests" (graines aléatoires) garantissant que tous les joueurs entrant le même numéro joueront sur les mêmes 10 rues (3 faciles, 3 moyennes, 4 difficiles).
- Un classement spécifique s'affiche à la fin de la partie pour comparer son score uniquement avec les autres joueurs ayant réalisé le même test.
